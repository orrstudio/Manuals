# 🖥️ Операционные системы

Эта папка содержит инструкции, настройки и материалы по различным операционным системам и загрузчикам.

## 📁 Подпапки

| Папка | Описание |
|-------|----------|
| `BOOTloaders/` | Загрузочные диск и папки /boot (grubThemes, UEFI-ArchLinux, UEFI-NixOs) |
| `Linuux/` | Linux: права доступа, файловые системы, установка Arch, NixOS-скрипты |
| `MacOS/` | macOS: установка, софт, тёмный режим, виртуализация, загрузочные флешки |
| `Windows/` | Windows: утилиты, офис, аудио/видео, фото, автоустановка (autounattend) |
