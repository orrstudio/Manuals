# 📘 Personal Manuals & Notes

Репозиторий с личными мануалами, инструкциями и заметками по различным темам: Linux, macOS, Windows, расширения браузеров, скрипты, резервные копии и приватные проекты.

## 📁 Структура репозитория

| Папка | Описание |
|-------|----------|
| `01 HELP & MAN/` | Советы по Linux, команды терминала, инструкции по ПО |
| `02 OS/` | Операционные системы: Linux, macOS, Windows, загрузчики |
| `03 EXTENSIONS/` | Расширения браузеров, флаги Chrome, Google Dorks, полезные ссылки |
| `04 PRIVAT/` | Приватные проекты, скрипты, ORACLE-серверы, outsourcing |
| `05 BackUps/` | Резервные копии конфигураций (браузеры, расширения) |
