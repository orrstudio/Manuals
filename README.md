## 📁 Структура репозитория

| Папка | Описание |
|-------|----------|
| `01 HELP & MAN/` | Советы по Linux, команды терминала, инструкции по ПО |
| `02 OS/` | Операционные системы: Linux, macOS, Windows, загрузчики (UEFI, GRUB, rEFInd) |
| `03 EXTENSIONS/` | Расширения браузеров, флаги Chrome, Google Dorks, полезные ссылки |
| `04 PRIVAT/` | Приватные проекты, скрипты, ORACLE-серверы, аутсорсинг |
| `05 BackUps/` | Резервные копии конфигураций (браузеры, расширения) |
