# 🔧 HizmetScripts — сервисные скрипты

Эта папка содержит сервисные bash-скрипты для автоматизации рутинных задач.

## 📄 Файлы

| Файл | Описание |
|------|----------|
| `delete_files_with_mlt.sh` | Удаление файлов с mlt |
| `delete_HAZIR.sh` | Удаление HAZIR |
| `mkdir_from_list_and_copy_file.sh` | Создание каталогов из списка и копирование файлов |
| `mkdir_HAZIR_and_copy_file_ornek.sh` | Пример создания каталога HAZIR и копирования файла |
| `rename_ornek_mlt_on_file_name.sh` | Переименование ornek_mlt в имя файла |

---

Сделано для личного использования.
