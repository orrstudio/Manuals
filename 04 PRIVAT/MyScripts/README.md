# 🐚 MyScripts — личные скрипты

Эта папка содержит личные bash-скрипты для автоматизации задач.

## 📁 Подпапки

| Папка | Описание |
|-------|----------|
| `HizmetScripts/` | Сервисные скрипты |
| `SSHMenu/` | Bash-скрипт для управления SSH-соединениями через меню dialog |

## 📄 Файлы

| Файл | Описание |
|------|----------|
| `ArchAppsInstaller.sh` | Скрипт установки приложений для Arch Linux |
| `FlatpakAppsInstaller.sh` | Скрипт установки приложений через Flatpak |
| `Yay-installer.sh` | Скрипт установки yay (AUR помощник) |

---

Сделано для личного использования.
